# TVRock Zoo — 予約・番組表 Ver.0.1.1

**TVRockを、もっと軽快に。**

ブラウザーでの操作に待ち時間を感じる方へ。予約一覧・番組表・自動検索予約を専用画面にまとめ、使い慣れたTVRockの録画環境をそのまま活かします。Ver.0.1.1（先行公開版）。

TVRockは、テレビ番組の録画予約・番組表・キーワードによる自動検索予約などを管理するソフトウェアです。チューナーや録画アプリと連携して録画を運用します。

TVRock Zooは、そのTVRockを使い続けながら、予約や番組表を見やすく操作するための**独立した非公式ツール**です。TVRock本体・録画エンジンの代替ではありません。録画は既存のTVRock側が担当します。TVRockの開発元とは関係ありません。

Zooという名前は「Two」とU2の「ZOO TV」に掛けたものです。これらの団体・アーティストとの提携を意味しません。

## できること

- 予約一覧を開始日時・長さ・局・番組名で表示。日付の境界は細い線で区切ります。
- ○で予約を無効化。下段の無効予約枠から×で復活。直前の切り替えを元に戻せます。
- 無効予約枠の折りたたみ、列幅・スクロール位置の保存。
- 1日24時間の番組表。局名バーは8時間ごと、ジャンルごとの淡い背景色。
- 自動検索予約の確認。対象行のダブルクリックでTVRockの編集画面を表示。
- 番組の詳細やおすすめ理由は、大きめのマウスオーバー表示。
- 最小化はタスクバーへ、閉じる操作は通知領域へ。通知アイコンはシングルクリックで表示。

## おすすめ予約

登録済みの検索条件や予約履歴を参考に、好みに近い番組を選んで予約する任意の機能です。有効にすると3日ごとに最大20件を追加し、既存予約とチューナーの空きを考慮します。選んだ理由は番組にマウスを置くと確認できます。

初期状態は**オフ**です。「おすすめ更新」の右クリックメニューで自動実行を切り替えます。手動で「おすすめ更新」を押した場合も実際の予約追加を行います。おすすめ番組は太字・斜体で表示します。

番組選びはPC内で行い、GPTなどの外部AIや有料APIは使いません。検索条件や番組情報を外部AIへ送信しません。文字の類似度を使う方式のため、好みの推定には限界があります。再放送やPR番組はおすすめ候補から除きます。

### GPTを使った検索条件づくりの例

GPTに好きな番組や避けたい内容を相談し、検索ワード・除外条件を提案してもらって、TVRockの自動検索予約へ自分で設定する使い方もできます。**アプリ内のGPT連携機能ではありません。** 外部サービスへ入力する内容はご自身で選んでください。

## 必要な環境と初回設定

1. Windows 10/11（64ビット）と、設定済みで動作するTVRockが必要です。現在の検証はTVRock 0.9u2系の既存環境で行っています。
2. .NETは同梱済みです。詳細編集に必要なWebView2はインストーラーが有無を確認し、未導入なら公式ダウンロードと再確認ボタンを表示します：[Microsoft公式ダウンロード](https://developer.microsoft.com/microsoft-edge/webview2/)。
3. インストーラーを実行し、TVRock Zooを起動します。
4. `dtv.ini`・`tvrock.sch`・`tvrock.key` のあるTVRockフォルダーと、このPCのTVRock Web URLを指定します。URL例は `http://127.0.0.1:8969/mon/`。ユーザー名・ポートは自分の環境に合わせます。
   TVRockが起動中ならフォルダーを自動検出します。URLはブラウザーの予約一覧のアドレスをそのまま貼り付けられます。
5. 「番組表を取得」で番組表を読み込みます。録画予約の実行はTVRockが続けて担当します。

接続先は同じPCのHTTPループバックに限定しています。LAN上の別PCのTVRockは今回のテスト版の対象外です。接続設定は「おすすめ更新」の右クリックから変更し、アプリを再起動して反映します。

## データとバックアップ

TVRock本体、BonDriver、録画ファイル、個人の予約・検索条件は配布物に含みません。設定・キャッシュ・操作前バックアップは `%LOCALAPPDATA%\TVRockZoo` に保存します。従来の個人用TsSchedulerとは別の保存先です。

予約変更時は、TVRockのWeb画面が使う手順を通して変更し、結果を予約ファイルで確認します。変更前のバックアップは自動保存します。「元に戻す」は直前の○・×操作用で、アプリ再起動後には引き継ぎません。録画開始直前・録画中の切り替えは保護します。

アンインストールしてもユーザーデータは残します。バックアップの手動復元は、録画が動作していない時にTVRockを終了してから行ってください。

## ソースからビルド

.NET 8 SDKとInno Setup 6を用意し、リポジトリ直下で実行します。

```powershell
.\scripts\build.ps1
```

`artifacts` にインストーラーと実行ファイルを作成します。.NET実行環境を同梱するwin-x64向けビルドです。合成データによるおすすめテストは次のコマンドで実行できます。

```powershell
dotnet run --project src/Recommend/TsRecommend.csproj -- --test
```

描画・読み込みの合成ベンチは `dotnet run --project tests/Bench.csproj -c Release` で実行できます。結果は `benchmark-results.json` に出力します。

## 速度の実測

このPCでの合成データ・Releaseビルドの測定では、予約500件の読み込みは中央値 **約2.4ms**（20回）、番組3000件を設定した番組表の描画・スクロールは **約21ms**（30回）、検索条件127件で番組3000件を評価するおすすめの類似度計算は **約0.64秒**（5回）でした。

これは個別のローカル処理の測定です。アプリ起動、TVRockからの番組表取得、予約追加の通信、ブラウザー版との直接比較を含みません。起動や予約完了が0.6秒という意味ではありません。環境・番組件数によって変わります。
