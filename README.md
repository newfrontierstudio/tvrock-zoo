# TVRock Zoo Ver.1.0.20

TVRockの予約一覧・番組表・自動検索予約を、軽快な専用画面で操作するWindows向け非公式ツールです。録画は既存のTVRockが担当します。

## はじめ方

1. 設定済みのTVRockと、Windows 10/11（64ビット）を用意します。
2. リリースからインストーラーを実行。.NETは同梱済みです。詳細編集用のWebView2がなければ公式サイトへ案内します。
3. TVRockフォルダーとWeb URLを指定します。起動中ならフォルダーを自動検出。普段の画面のURLを貼り付けられます。
4. 「番組表を取得」で読み込みます。

別PCの録画サーバーは、詳細設定の「接続先」でURLと読み取り可能な共有フォルダーを指定します。接続先は複数保存できます。URL例：`http://127.0.0.1:8969/ユーザー名/`。

更新はZooを終了して上書きインストールしてください。通常はアンインストール不要で、保存済みの設定を引き継ぎます。

## 今回の改善

番組表で予約済みと未予約を見分けやすくし、予約済みの番組にチューナー番号を表示します。TVRockの予約先IDと録画アプリの設定を照合し、確認できた割当先を表示します。マウスオーバーで名前の全文を確認できます。

番組表は局の列を画面幅に合わせ、横スクロールなしで表示するようにしました。既存の予約・設定は引き継ぎます。

## 録画の開始・終了を調整

予約行を右クリックして秒数を指定します。開始は−で早く／＋で遅く、終了は−で短縮／＋で延長。「今後も常に」は同じ局・番組名の先頭一致で、既存予約にも上書きします。常時適用はZoo起動中に動作します。

## おすすめ予約

**① まずはZooにおまかせ（ChatGPT不要）**

「自動おすすめ予約」をONにするだけ。検索条件や予約履歴を参考に、Zooが関連する番組を選んで予約します。ふだんはこれでOK。「おすすめ更新」で今すぐ実行できます。自動実行は初期OFFです。

**② ChatGPTで、もっと好みに合わせる（任意）**

1. 「ChatGPT」→「ChatGPTに相談する」を押すと、相談文がコピーされChatGPTが開きます。
2. ChatGPTに貼り付けて送信し、好きな番組・避けたい内容を答えます。
3. 最後の回答をコピーし、Zooの「ChatGPTの回答を取り込む」→「内容を確認」で適用します。

次のおすすめ選びから反映します。今すぐ選ぶには「おすすめ更新」。取り込んだ好みはZooのおすすめ専用で、既存予約やTVRockの検索条件は変えません。ChatGPTはブラウザーで利用でき、APIキーは不要です。Zooから予約履歴などを自動送信することはありません。

## 番組表からの予約先選択

番組から予約すると、録画前後の確保時間も含めた予約上の空きチューナーを表示します。空きがなければ「再配置案を確認」で既存予約の変更をできるだけ少なくする案を探し、内容を確認して適用できます。録画中・開始直前・繰り返し・秒単位の予約や、別PC・特殊な録画予約は再配置の対象外です。

TVRockの変更は一括保存ではありません。途中で通信が途切れた場合は再送せず、確認済み件数を表示して新規予約を停止します。予約一覧を確認してください。予約状況が変わった場合も再確認が必要です。実機での長時間運用・全構成の検証は継続中です。

## アンインストール

1. 録画の終了を待ち、通知領域の右クリックメニューからアプリを完全終了します。
2. Windowsの「設定 → アプリ」で製品名を選んでアンインストールするか、スタートメニューの「アンインストール」を実行します。

アプリ本体とショートカットを削除します。**録画ファイル・予約・設定は残ります。TVRock・TVTestおよび他のアプリは削除しません。** 保存先をアプリのフォルダー内にした場合も、利用者が作成したファイルは削除対象に追加しません。

再インストール時に保存済みの設定を利用できます。データを消す操作はアンインストールに含めていません。

## 診断ログ

詳細設定の「診断ログ ON／OFF」で追加の診断ログを切り替えます。初期状態はOFFで、選択は保存されます。OFFでもエラーの概要と録画結果は残し、既存のログは削除しません。

追加の診断ログは通信の成否・所要時間や予約保存などを記録します。番組名・接続先URL・個人のパス・応答本文・例外のメッセージは記録せず、自動送信もしません。ログは1ファイル約1MBを上限に前回分へ切り替えます。
保存先：接続先ごとの設定フォルダー（通常 `%LOCALAPPDATA%\TVRockZoo`）の `diagnostic.jsonl` と `errors.jsonl`。
