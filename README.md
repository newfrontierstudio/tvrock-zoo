# TVRock Zoo Ver.1.0.15

TVRockの予約一覧・番組表・自動検索予約を、軽快な専用画面で操作するWindows向け非公式ツールです。録画は既存のTVRockが担当します。

## はじめ方

1. 設定済みのTVRockと、Windows 10/11（64ビット）を用意します。
2. リリースからインストーラーを実行。.NETは同梱済みです。詳細編集用のWebView2がなければ公式サイトへ案内します。
3. TVRockフォルダーとWeb URLを指定します。起動中ならフォルダーを自動検出。普段の画面のURLを貼り付けられます。
4. 「番組表を取得」で読み込みます。

別PCの録画サーバーは、詳細設定の「接続先」でURLと読み取り可能な共有フォルダーを指定します。接続先は複数保存できます。URL例：`http://127.0.0.1:8969/ユーザー名/`。

更新はZooを終了して上書きインストールしてください。通常はアンインストール不要で、保存済みの設定を引き継ぎます。

## 今回の改善

複数チューナー環境で、番組表から予約すると予約先と設定が一致しないと表示される問題を改善しました。固定の番号を仮定せず、TVRockの予約画面にあるチューナー一覧と設定を照合します。TSTaskを使う構成を含め、合成データによる照合テストを実施しています。全実機構成での動作確認は継続中です。

詳細設定に「接続・チューナーを確認」を追加しました。照合件数と予約先IDをその場で確認でき、予約は変更しません。診断表示にはPC名・ユーザー名・設定フォルダーのパス・個人の予約一覧を含めません。録画アプリと局の設定はTVRock本体で行います。

録画時間帯は赤地・白文字のアイコンで本数を表示し、通知領域のマウスオーバーで局・番組名・終了予定を確認できます。Zooの表示は予約時刻基準で、録画ファイルの生成を確認した表示ではありません。

おすすめは白い「自動」「GPT」バッジで区別します。「GPT」は取り込んだ好み条件を参考にした意味で、最終的な番組選定はPC内で行います。局の色編集・並び替え、スクロール表示、録画時間帯の枠線も調整しました。

## 録画の開始・終了を調整

予約行を右クリックして秒数を指定します。開始は−で早く／＋で遅く、終了は−で短縮／＋で延長。「今後も常に」は同じ局・番組名の先頭一致で、既存予約にも上書きします。常時適用はZoo起動中に動作します。

## おすすめ予約

**① まずはZooにおまかせ（ChatGPT不要）**

「自動おすすめ予約」をONにするだけ。検索条件や予約履歴を参考に、Zooが関連する番組を選んで予約します。ふだんはこれでOK。「おすすめ更新」で今すぐ実行できます。自動実行は初期OFFです。

**② ChatGPTで、もっと好みに合わせる（任意）**

1. 「ChatGPT」→「ChatGPTに相談する」を押すと、相談文がコピーされChatGPTが開きます。
2. ChatGPTに貼り付けて送信し、好きな番組・避けたい内容を答えます。
3. 最後の回答をコピーし、Zooの「ChatGPTの回答を取り込む」→「内容を確認」で適用します。

次のおすすめ選びから反映します。今すぐ選ぶには「おすすめ更新」。取り込んだ好みはZooのおすすめ専用で、既存予約やTVRockの検索条件は変えません。ChatGPTはブラウザーで利用でき、APIキーは不要です。Zooから予約履歴などを自動送信することはありません。

## 速度・検証

合成データの中央値：予約500件の読み込み約1.4ms、番組表描画約21ms、おすすめ計算（3000番組・127条件）約0.73秒。起動・TVRock通信・予約書き込みは含みません。詳細は[BENCHMARKS.md](BENCHMARKS.md)。

インストール・実行テスト・アンインストールは検証済み。新規PCのWebView2導入と全録画構成の確認は未完了です。実行ファイルの署名は未取得です。

## データ・ソース

設定と変更前バックアップは `%LOCALAPPDATA%\TVRockZoo` に保存し、アンインストール後も残します。TVRock本体・BonDriver・録画は配布に含みません。

.NET 8 SDKとInno Setup 6を用意し、`scripts/build.ps1` でビルドできます。依存ライブラリは[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)を参照してください。
