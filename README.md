# TVRock Zoo Ver.0.1.2

TVRockの予約一覧・番組表・自動検索予約を、軽快な専用画面で操作するWindows向け非公式ツールです。録画は既存のTVRockが担当します。

## はじめ方

1. 設定済みのTVRockと、Windows 10/11（64ビット）を用意します。
2. リリースからインストーラーを実行。.NETは同梱済みです。詳細編集用のWebView2がなければ公式サイトへ案内します。
3. TVRockフォルダーとWeb URLを指定します。起動中ならフォルダーを自動検出。普段の画面のURLを貼り付けられます。
4. 「番組表を取得」で読み込みます。

接続は同じPCのTVRockのみ対応。URL例：`http://127.0.0.1:8969/ユーザー名/`。

## おすすめ予約

登録済みの検索条件と予約履歴を参考に、好みに近い番組を選びます。有効にすると、3日ごとに最大20件を予約します。

**ChatGPTがなくても、すべての標準機能は問題なく動作します。**

ChatGPTを活用する場合は、好きな番組や避けたい内容を相談し、提案された検索ワード・除外条件をTVRockへ設定します。その検索条件がおすすめ選びにも反映されます。

現在はChatGPTとの直接連携ではなく、**提案をユーザーが設定する方式**です。

初期状態はオフ。「おすすめ更新」の右クリックで有効化し、Zooを起動しておきます。手動更新も実際の予約追加を行います。選んだ理由はマウスオーバーで確認できます。

## 速度・検証

合成データの中央値：予約500件の読み込み約1.5ms、番組表描画約22ms、おすすめ計算（3000番組・127条件）約0.68秒。起動・TVRock通信・予約書き込みは含みません。詳細は[BENCHMARKS.md](BENCHMARKS.md)。

インストール・実行テスト・アンインストールは検証済み。新規PCのWebView2導入と全録画構成の確認は未完了です。署名なしの先行公開版です。

## データ・ソース

設定と変更前バックアップは `%LOCALAPPDATA%\TVRockZoo` に保存し、アンインストール後も残します。TVRock本体・BonDriver・録画・個人設定は配布に含みません。

.NET 8 SDKとInno Setup 6を用意し、`scripts/build.ps1` でビルドできます。ソースのライセンスは未設定です。依存ライブラリは[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)を参照してください。
